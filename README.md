# Count-It: The Inventory Management System

**Count-It** is a modern Inventory Management System designed to simplify stock management and allocation processes. Built with the latest technologies, it ensures ease of use and reliability for businesses and institutions.

---

## 🚨 Project Status: **Indefinite Hiatus**
⚠️ **This project is not under active development or maintenance.**

---

## 🚀 Features
- **Real-Time Inventory Tracking**
- **Seamless Allotment Management**
- **Efficient Returns Handling**
- **Role-Based User Access**
- **User-Friendly Interface**

---

## 🛠️ Tech Stack
- **Backend:** Spring Boot (⚠️ **Closed Source**)
- **Frontend:** React.js
- **Database:** MongoDB Atlas
- **Hosting:** Render
- **Containerization:** Docker

---
